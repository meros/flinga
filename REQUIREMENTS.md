# Telia Lite: features and requirements

The owner's requirements for the thin Telia Play client, in the order they were given. Every change must keep
the whole set coherent. When a new feature does not fit the current UX, rebuild the UX; do not bolt it on.

Status: ✅ done and verified on the TV · 🟡 built, verified offline only · ⬜ not started

## Guiding principle

**U0 Seamless, as few modes as possible** (owner: "Jag vill att allt ska vara så sömlöst och få lägen som möjligt"). Every surface, key and overlay behaves the same way whatever plays (live, delayed live, catch-up, VOD). Technical differences (start-over stream vs live window, catch-up vs VOD) never surface as a visible mode, label or different key meaning. When a design choice adds a state the user must know about, find a way without it. Reviewers treat a needless mode as a medium finding.
